EXPERIENCE NORMALIZATION PROCEDURE
------------------------------------------

     - company
     - location
     - employment type
   Examples:

     - Acme Corp
     - Vancouver, BC

3. BODY (bullet)
   - Sentence-like responsibilities / achievements
   Examples:

     - Improved latency by 35%

AMBIGUOUS-LINE RULES
------------------------------------------

- Date-only line → MUST go to meta
- Company-only line → prefer meta
- Location-only line → prefer meta
- Sentence-like text → MUST go to body
- If a line mixes title + date:
    - title → header
    - date → meta
- If unsure between meta and body → choose BODY

STRICT PROHIBITIONS:
- NEVER place date-only text in header
- NEVER place sentence-like text in meta
- NEVER mix semantic types inside header/meta/body
