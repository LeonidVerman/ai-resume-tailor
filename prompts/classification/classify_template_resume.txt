ROLE RECONSTRUCTION
==================================================

IGNORE parser-provided roles as final truth.
You MUST rebuild roles from paragraph sequence when needed.

A NEW ROLE STARTS when ANY of these are true:

1. Paragraph contains date range, company, location, or employment metadata.
2. Paragraph followed by bullets and looks like a job title.
3. Pattern appears: meta -> title -> bullets.
4. A role_header or role_meta appears after body content has already started.

Algorithm:
- iterate sequentially through paragraphs
- when a new role start is detected, close previous role and start new role

Role structure:
header_blocks:
- job title if present
- else first non-meta paragraph

meta_blocks:
- dates
- company
- location
- employment mode

body_blocks:
- role-local content after header/meta
- includes both rewrite candidates and preserved adjunct blocks

Strict rules:
- NEVER allow role_header inside body_blocks
- NEVER allow role_meta inside body_blocks
- if encountered, treat as a new role boundary or move to header/meta

Failsafe:
- if a role has more than 15 rewriteable bullets and a clear meta/header boundary appears, split using the nearest boundary

Final guarantee:
- each role = one job
