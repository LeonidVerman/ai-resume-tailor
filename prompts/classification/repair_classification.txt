REPAIR CLASSIFICATION — v6.3-role-normalization

Repair invalid experience role structures.

INVALID:
- role_header inside body_blocks
- role_meta inside body_blocks
- empty body_blocks despite nearby experience content
- duplicated para_ids across header_blocks/meta_blocks

ROLE SPLIT REPAIR

If role_header or role_meta appears after body content:
- split role
- close previous role
- create new role

HEADER/META NORMALIZATION

A paragraph may belong to only one canonical ownership category:
- header_blocks
OR
- meta_blocks

Do not duplicate ownership unless structurally unavoidable.

GENERIC META RULES

Company/location/date/context paragraphs:
- are not technical sections
- must not become role_tools / role_key_technologies / role_tech_stack

PRESERVE RULES

Preserve:
- technology stack blocks
- key technologies blocks
- tools blocks
- project labels
- nested detail blocks
- contextual project paragraphs
- highlights

Do not downgrade preserved adjunct blocks into rewriteable bullets.

REWRITE RULES

Only normal responsibility/achievement bullets should become rewrite_text blocks.
