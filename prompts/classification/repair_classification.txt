SECTION CONTRACTS
==================================================

SUMMARY
If semantic_type = "summary":
- rewrite_policy = "rewrite_body"
- roles[] must be empty
- all blocks must be:
  - summary_paragraph
  - rewrite_text
- preserve_heading = false
- preserve_body_structure = false

SKILLS
If semantic_type = "skills":
- rewrite_policy = "rewrite_body"
- roles[] must be empty
- all blocks must be:
  - skills_paragraph
  - rewrite_text
- preserve_heading = false
- preserve_body_structure = false

EXPERIENCE
If semantic_type = "experience":
- rewrite_policy = "rewrite_bullets_only"
- blocks[] must be empty
- roles[] must be populated

For each role:
- header_blocks:
  - semantic_type = "role_header"
  - rewrite_policy = "preserve"
- meta_blocks:
  - semantic_type = "role_meta"
  - rewrite_policy = "preserve"
- body_blocks:
  - semantic_type = "bullet"
  - rewrite_policy = "rewrite_text"

Experience normalization rules:
- role title / position name -> header
- compact employment metadata -> meta
- dates -> meta
- company / employer -> meta
- location -> meta
- sentence-like responsibility / achievement text -> body
- do not place sentence-like text into meta
- do not place date-only text into header
- do not place metadata into body unless no safer structure exists

EDUCATION
If semantic_type = "education":
- rewrite_policy = "preserve"
- roles[] must be empty
- all blocks must be:
  - education_entry (ONLY — never other_paragraph, never role_header, never role_meta)
  - preserve

Any block in an education section that is role_header, role_meta, other_paragraph,
summary_paragraph, or skills_paragraph MUST be converted to education_entry.
This includes pipe-format degree/date lines (e.g. "BACHELOR OF SCIENCE | MAY 2014")
which the parser may have labelled role_header — inside education they are education_entry.

PROJECTS
If semantic_type = "projects":
- rewrite_policy = "preserve"
- roles[] must be empty
- all blocks must be:
  - project_entry OR other_paragraph
  - preserve

ADDITIONAL
If semantic_type = "additional":
- rewrite_policy = "preserve"
- roles[] must be empty
- all blocks must be:
  - additional_item OR other_paragraph
  - preserve

OTHER
If semantic_type = "other":
- rewrite_policy = "preserve"
- roles[] must be empty
- all blocks must be:
  - other_paragraph
  - preserve
